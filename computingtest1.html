2. Binary ↔ Hexadecimal

Hex Map: 0–9 remain standard numbers. 10=A, 11=B, 12=C, 13=D, 14=E, 15=F.

  • Binary → Hex: Split 8 bits into two 4-bit nibbles (8 4 2 1 each). Convert each nibble to Hex.
  • Hex → Binary: Convert each Hex digit into its 4-bit binary nibble equivalent.

3. Binary Addition

Rules:

  • 0 + 0 = 0
  • 0 + 1 = 1
  • 1 + 1 = 0 (carry 1)
  • 1 + 1 + 1 = 1 (carry 1)

Overflow: Occurs when the sum exceeds the available bit capacity (e.g. sum > 255 in 8-bit).

4. Binary Shifting

  • Left Shift (<< n): Shifts bits left by n places; pad 0s on the right. Multiplies by 2n.
  • Right Shift (>> n): Shifts bits right by n places; pad 0s on the left. Divides by 2n (integer division).
